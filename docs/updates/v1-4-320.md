## AI Catalog Curation with Gemini & OpenRouter

NoxMedia v1.4.320 introduces AI-driven library curation, removing the need to manually sort through thousands of files or construct complex queries.

### Key Highlights
- **Natural Language Prompts**: Instruct NoxMedia to build collections like *"Atmospheric neo-noir thrillers set in raining cities"* or *"Wholesome studio anime films"*.
- **Direct LLM Integration**: Connect your personal **Google Gemini API Key** or **OpenRouter API Key** directly in the app settings.
- **Deep Semantic Matching**: Evaluates plots, keywords, directors, and genres to assemble cohesive themed shelves.
- **Instant Client Mirroring**: Any AI shelf is mirrored across Nuvio and Jellyfin-compatible players immediately.
