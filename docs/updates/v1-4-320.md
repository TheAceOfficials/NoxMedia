## 🤖 AI Catalog Curation with Gemini & OpenRouter

NoxMedia v1.4.320 introduces AI-driven library curation. You no longer have to manually sort through thousands of Telegram files or set complicated boolean filters.

### 🌟 Key Highlights
- **Natural Language Prompts**: Ask NoxMedia to build shelves like *"Atmospheric neo-noir thrillers set in raining cities"* or *"Wholesome studio anime movies"*.
- **Direct LLM Integration**: Connect your own **Google Gemini API Key** or **OpenRouter API Key** directly in the app settings.
- **Deep Semantic Matching**: Evaluates plots, keywords, directors, and genres to assemble cohesive themed shelves.
- **Instant Stremio & Nuvio Export**: Any AI shelf is instantly mirrored across Stremio and Nuvio clients.
