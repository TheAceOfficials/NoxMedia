## ⏱️ Media Runtime & Metadata Precision

This release focuses on metadata accuracy and playback stability across Apple and Android streaming clients.

### 🌟 Key Highlights
- **Accurate Runtime Calculation**: Telegram files without explicit duration metadata now pull fallbacks directly from TMDB episode and movie records.
- **Anime Title Sanitization**: Improved multi-language anime title stripping (Kanji, Romaji, and English season titles).
- **Foreground Service WakeLocks**: Strengthened background service resilience to ensure uninterrupted playback while Android enters deep sleep.
